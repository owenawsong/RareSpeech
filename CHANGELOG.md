# Changelog

## 0.1.0

- Authored 320-case English candidate collection with 64 term families and frequency provenance.
- Command, Python, speech API and existing-audio integration routes.
- Resumable generation, audio hashes, conservative alignment, WER and target retention.
- Category tables, family bootstrap, missing-data coverage and checkpoint comparison.
- Offline audio reports, listening reviews with consensus coverage, model-card export.
- Static explorer, documented measurement limitations, package build and CI.

This release does not claim expert-validated pronunciation references or a
human-quality leaderboard. Measured model examples are integration pilots.
