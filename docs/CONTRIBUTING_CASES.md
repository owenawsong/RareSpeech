# Contribute a challenge

1. Give the term a specialist source and frequency evidence. A missing frequency entry needs corroboration, not a claim of zero occurrence.
2. Document accepted pronunciations, language/accent scope, and legitimate alternatives. Unresolved pronunciations stay candidate/uncertain.
3. Write original, coherent carrier text. Do not copy copyrighted paragraphs or manufacture scientific facts.
4. Anchor every intended target occurrence with exact character offsets. Avoid overlapping spans.
5. Group controlled variations with a family ID. Avoid inflating sample size by treating repeats as independent terms.
6. Specify why the case is useful: unfamiliar vocabulary, density, confusable entries, or extended-content retention.
7. Include acceptance rules for numbers/abbreviations if applicable. New aliases require a corpus revision.
8. Run `rarespeech validate --corpus your-cases.jsonl` and tests.

No generated model verdicts belong in the reference corpus. AI-assisted candidate authoring is allowed, but does not substitute for qualified validation. Submitted original text is licensed CC BY-SA 4.0; code is MIT.
